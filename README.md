# Student Performance Prediction System

A Machine Learning project that predicts whether a student will pass or fail based on study hours, attendance, and previous scores. The project uses Linear Regression for prediction and GitHub for version control.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Git
* GitHub

## Project Files

* student_data.csv
* student_prediction.ipynb
* requirements.txt

## Features

* Data Loading and Exploration
* Data Preprocessing
* Linear Regression Model Training
* Student Performance Prediction
* GitHub Version Control
